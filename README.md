# Aura Medical Clinic

Site demo single-page pentru o clinică de estetică high-end, construit cu Next.js și Tailwind CSS.

## Tratamente

1. Anti-riduri Dysport®
2. Anticelulită Powershape™2
3. Epilare definitivă full body
4. Lifting facial HIFU Microson™ Pen
5. Facial Octoline

## Rulare locală

```bash
npm install
npm run dev
```
